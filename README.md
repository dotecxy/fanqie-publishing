# fanqie-publishing

番茄作家章节发布 Skill：通过浏览器界面核对、导入与按序提交章节，保留逐章正文基线及后台回执。

## 能做什么

- 从实时章节管理和草稿箱恢复任务，避免重复上传或提交。
- 批量导入 DOCX，逐章比对平台解析全文与原稿。
- 用单章短流程减少重复探索和等待，最终提交保持串行。
- 处理动态分页、空白末页、标题冲突、页面状态过期及结果截断。
- 区分已上传、已提交审核、审核中和已发布。

## 安装与使用

将仓库完整复制到支持 Agent Skills 的工具所读取的 `fanqie-publishing` 技能目录，保留 `SKILL.md` 和 `references/` 的相对结构。例如，使用 Cindy 的共享用户技能目录：

```bash
git clone https://github.com/dotecxy/fanqie-publishing.git ~/.agents/skills/fanqie-publishing
```

新建或重启 Agent 会话后，让它使用 `fanqie-publishing`，并明确作品、稿源、章节范围和发布方式。例如：

> 将这部作品草稿箱中的所有非空章节按序提交审核。遇到重名时，只修改后面章节的标题，正文保持不变。

## 使用条件

这是工作流指导，不是自动运行的发布程序。执行 Agent 需要可用的浏览器自动化工具、已登录的番茄作家后台和作者对本次发布范围的授权。项目已有 `AGENTS.md` 或发布指南时，先读取其中的项目事实。

AI 使用声明必须按实际创作情况选择。示例页码、选择器、文件限制与旧工具超时只来自验证案例；执行时以当前页面和工具文档为准。仅通过网站 UI 操作，不依赖登录 Cookie 或私有发布接口。

发布终章不等于审核全部通过，也不等于已经提交平台的完结申请。
