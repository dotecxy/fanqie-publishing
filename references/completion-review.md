# 完结申请被驳回的排查

适用于完结申请审核不通过、作品状态仍是“连载中”、或用户说“我被驳回/说结尾没写完”。以下驳回文案、标题规则与状态变化来自真实账号验证（2026-11）。

## 1. 先读驳回原文，不要先猜

作品通知里写得很具体，先拿到它：

- 入口：`https://fanqienovel.com/main/writer/message`（左侧“消息通知”，有未读时带数字角标）
- 分类看“作品通知”，一条典型的驳回是：

> 完结申请审核不通过，请修改作品内容，补全结尾，在 3 天后重新发起完结申请

关键是末尾那句“**3 天后**”——这是硬性等待期，重试之前先确认日期。同一入口还能看到“作品审核已通过”“章节审核不通过（已标问题）”等其他通知，不要混为一谈。

## 2. “补全结尾”通常不是缺章节

收到这句话时，最容易犯的错是回去数章节、重发末章。**先做完整性核对，再判断是不是内容问题**——多数情况下结构是好的：

| 核对项 | 方法 | 合格标准 |
| --- | --- | --- |
| 平台总章数 | 逐卷翻页全量抓取章号 | 等于本地章数，无重复、无缺失 |
| 卷分布 | 每卷实际起止章号 | 与大纲一致，五卷加总等于总数 |
| 章节状态 | 每行状态列 | 无“未通过”，末章为“已发布” |

本项目实测：平台 975 章齐全、五卷 150+229+186+200+210 全部对得上、零重复零缺失、全部“已发布”，但完结申请仍被驳回。**所以结构完整不能证明完结申请会通过。**

## 3. 真正的原因：末章标题缺完结标记

平台判断“结尾是否补全”看的是**章节标题里的完结标记**，不是正文有没有收束。全书 975 个标题都不含“大结局/终章/全书完”时，作品状态会一直停在“连载中”，完结申请容易被判为结尾未补全。

核对方法：

- 看末章标题与最后几章标题，是否含 `大结局` / `终章` / `完结` / `全书完`
- 看作品信息页“更新状态”是否为“连载中”
- 用 `grep -l "^# .*\(大结局\|终章\|完结\)" 正文/*.md` 可确认全书都没有标记

## 4. 改末章标题的做法

标题在已发布章节上也能改，且**不会触发重新审核**（本项目实测改完状态仍为“已发布”，正文字数不变）。

1. 章节管理 → 选末章所在卷 → 定位末章行
2. 行末操作列 `.tomato-edit`（铅笔图标）→ 链接形如 `/main/writer/<book_id>/publish/<item_id>/?enter_from=modifychapter`
   - 注意：编辑链接在**空的最后一列**，不是标题单元格；标题本身只链到预览页
3. 编辑页按真实输入方式改标题（受控输入，用 `Input.insertText` 或原生 value setter + `input` 事件）
4. 下一步 → 发布设置核对标题与卷 → 如实选 AI → 确认提交
5. **只改标题**，正文一字不动；提交后核对正文字数与改前一致
6. 提交后复核章节管理，标题已更新且状态仍“已发布”

标题命名写法（按原题保留程度排序）：

| 写法 | 特点 |
| --- | --- |
| `原标题（大结局）` | 改动最小，保留原题，推荐 |
| `大结局 原标题` | 标记最靠前，识别率最高，但改写原题 |
| `原标题（全书完）` | 与正文末尾风格呼应 |

标题长度上限 30 字（页面计数器显示 `n/30`），中文字符与全角标点各计 1。

## 5. 同时同步本地文件

改完平台标题后，本地正文文件也要一致，否则下次批量核对会报标题不符：

- 重命名 `正文/第975章_原标题.md` → `正文/第975章_原标题（大结局）.md`
- 文件首行 `# 第N章 原标题` 同步加上标记
- 重新确认文件总数不变（不要复制成两份）

## 6. 硬性等待与复查

- 驳回通知明确要求 3 天后重新发起，**不要当天重试**。记录驳回日期，算准最早可再次申请的日期。
- 等待期结束后先看作品信息页“更新状态”：已变“已完结”则不用再申请；仍是“连载中”才重新发起完结申请。
- 完结申请通过 ≠ 所有事项完成：签约、推荐位等是独立流程，不因完结自动生效。

## 7. 常见误判

| 误判 | 事实 |
| --- | --- |
| “说结尾没了，肯定是章节没发全” | 结构完整也会被驳回；先查末章标题有无完结标记 |
| “末章正文明明收束得很好” | 平台看标题标记，不读正文判断是否完结 |
| “已发布章节不能改标题” | 能改；通过 `.tomato-edit` 进 modifychapter 编辑页 |
| “改标题会重新审核、掉发布状态” | 实测不会，状态仍“已发布” |
| “被驳回了马上再交一次” | 有 3 天等待期，提前提交无效 |
| “完结申请通过就自动完结了” | 状态变化与签约/推荐相互独立，逐项确认 |
